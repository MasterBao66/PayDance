# PRODUCT

> [English version →](PRODUCT_EN.md)

本文固定薪跳 PayDance 的产品定位、能力边界和取舍原则。

## 一句话定位

薪跳 PayDance 是一款桌面实时工资看板，让今日入账安静常驻、实时跳动、随时可扫一眼。

## 适合谁

- 主要使用 Windows 11，希望更直观看见工作时间价值的用户。
- 偏好轻量工具的用户：无账号、本地保存、不上传数据。
- 需要置顶、托盘和迷你悬浮金额窗口，长期低打扰常驻的用户。
- 想先在网页里试试手感，再决定是否下载桌面版的用户。

## 产品边界

以下方向暂不进入产品范围：

- 快捷键/热键
- 提醒/通知/弹窗
- 历史时间轴、图表或趋势分析
- 打卡、考勤或工时统计
- 云端同步、账号体系或在线服务
- 把迷你悬浮模式扩展成复杂面板
- 把 Web Preview 宣传成完整桌面版

新功能先回答一个问题：它能否让用户更轻松地看见“今天正在挣到的钱”？

## 体验原则

- 主窗口负责完整信息，迷你悬浮窗口负责低存在感的金额常驻。
- 薪资口径贴近真实工作制：月薪、日薪、时薪、每周工作日、午休剔除、跨零点夜班。
- 本地优先：薪资与作息配置只保存在本机，不做登录、云同步、遥测或广告。
- 薪资说明和设置中心属于低频入口，不抢主界面注意力。
- 错误提示简洁、直接、可执行。

## 平台策略

当前官方发布与验证优先级是 Windows 11，桌面版承载托盘、置顶、透明窗口、迷你悬浮、系统材质和开机自启动等完整能力。Web Preview 作为线上体验入口部署在 Vercel 主站，GitHub Pages 作为仓库镜像与发布验证入口。

这并不排斥 macOS、Linux 等平台。社区贡献者可以先提交平台适配方案与验证结果；正式发布前，仍需明确构建、验证、更新和维护边界。
