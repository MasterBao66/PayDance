# PRODUCT

> [English version →](PRODUCT_EN.md)

## 一句话定位

薪跳 PayDance 是一款桌面实时工资看板，让今日入账在桌面上常驻、实时增长、随时可扫一眼。

## 适合谁

- 希望在 Windows 11 桌面实时查看今日收入的用户。
- 需要托盘、置顶或迷你悬浮窗的用户。
- 想先通过 Web Preview 体验界面和计算方式的用户。

## 产品边界

以下方向暂不进入产品范围：

- 快捷键/热键
- 提醒/通知/弹窗
- 历史时间轴、图表或趋势分析
- 打卡、考勤或工时统计
- 云端同步、账号体系或在线服务
- 把迷你悬浮模式扩展成复杂面板
- 把 Web Preview 宣传成完整桌面版

新增功能应直接服务于“查看今天正在挣到的钱”。

## 体验原则

- 主窗口展示完整信息，迷你悬浮窗只显示实时金额。
- 薪资口径贴近真实工作制：月薪、日薪、时薪、每周工作日、午休剔除、跨零点夜班。
- 薪资与作息配置只保存在本机；不提供登录、云同步、遥测或广告。
- 薪资说明和设置中心属于低频入口，不抢主界面注意力。
- 错误提示简洁、直接、可执行。

## 平台策略

官方桌面版目前面向 Windows 11，支持托盘、置顶、透明窗口、迷你悬浮窗和开机自启动。Web Preview 部署在 Vercel，GitHub Pages 保留仓库镜像。

这并不排斥 macOS、Linux 等平台。社区贡献者可以先提交平台适配提案与构建、验证结果；正式发布前还需明确更新和维护范围。
