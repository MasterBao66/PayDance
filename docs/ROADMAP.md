# 路线图

> [English version →](ROADMAP_EN.md)

本文记录薪跳 PayDance 的开发方向。它不是发布时间承诺，而是帮助维护者、贡献者和用户快速理解当前优先级。

## 最近完成

当前能力基线，逐版本明细见 [CHANGELOG](../CHANGELOG.md)：

- **桌面可靠性**：混合时钟在长时间休眠或系统时间跳变后重新校准；跑出屏幕的窗口能被拉回可见区域；迷你悬浮模式不再占用任务栏图标。
- **本地设置**：配置迁移走显式版本链，损坏或未来版本的设置按项修复后写回，写盘失败在界面可见。
- **发布与供应链**：Release 执行 Windows EXE 自动启动冒烟与单实例检查，并生成 SPDX SBOM；CodeQL 覆盖 TypeScript 与 Rust；GitHub Actions 固定到 Commit SHA，安全工具下载全部校验 SHA256。
- **官网与可访问性**：Web Preview 接入 CI 的多视口截图、axe-core 与像素差异门禁；中英文入口在 Vercel 主站与 GitHub Pages 镜像上线。

## 当前

- 发布链路只剩人工尾项：便携版自动更新路径的真实验证，以及更新密钥轮换演练。
- 系统时间校准补齐大幅回拨、时区切换、跨天与夜班边界。
- 多显示器恢复优先保留仍然有效的副屏位置，并提供重置窗口位置入口。
- 后台更新错误可见：网络失败保持低打扰，清单异常与签名验证失败给出明确提示。
- 首次启动向导加入示例预览，配置时即可看到今日预计、每分钟收入与午休暂停。

## 接下来

- Authenticode 代码签名，降低 Windows SmartScreen 误报。
- 迷你悬浮窗口右键菜单：透明度、重置位置、恢复主窗口。
- 继续扩展只能在真实 Windows 会话验证的能力：托盘点击、重启后自启动、真实休眠恢复。
- 更新签名真实验签。
- 发布经过产品边界审核的用户可见新手任务，形成公开反馈闭环。

## 以后

- 按币种的分组分隔符与小数位规则，同时保持主界面轻量，不引入汇率、税务或财务分析。
