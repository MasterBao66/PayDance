# 获取帮助

> [English version →](SUPPORT_EN.md)

多数使用、隐私和许可问题在 [常见问题](FAQ.md) 里已有答案；某个版本改了什么看 [更新日志](../CHANGELOG.md)，某个方向做不做看 [产品定位与边界](PRODUCT.md)。

## 使用问题

想确认某个功能该怎么用，可以先在 [GitHub Issues](https://github.com/MrBaoboer/PayDance/issues) 搜索关键词。没有相关讨论时，提交一个普通 Issue，写清使用场景和期望结果。

## Bug 反馈

优先使用仓库里的 Bug 反馈表单，并尽量提供：

- 应用版本，例如 `v0.9.9`
- 系统环境，例如 Windows 11 23H2
- 稳定复现步骤，或大致触发场景
- 期望结果与实际结果
- 截图、录屏或报错片段

不要公开粘贴薪资数据、配置文件、私钥或其他个人敏感信息。

## 功能建议

提建议前先看 [产品定位与边界](PRODUCT.md)，说明这个建议解决的具体场景，以及它为什么服务“桌面实时工资看板”这一核心。平台适配建议还需要说明目标系统、验证方式和你愿意维护的范围。

## 安全漏洞

安全漏洞不要通过公开 Issue 报告，按 [SECURITY.md](../.github/SECURITY.md) 中的方式私下报告。

## 联系作者

项目由 Mr.Baoboer 独立开发与维护。可以通过 [作者 GitHub 首页](https://github.com/MrBaoboer) 上公示的邮箱联系，或在相关 Issue 中 at 作者。
