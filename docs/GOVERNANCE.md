# 治理说明

> [English version →](GOVERNANCE_EN.md)

维护者（见 [维护者说明](MAINTAINERS.md)）决定产品边界、发布节奏、许可证、商标和合并结果。贡献流程见 [贡献指南](../.github/CONTRIBUTING.md)。

## 决策原则

- 先守住核心体验：本地优先、低打扰的桌面实时工资看板。
- 优先接受范围小、可验证、维护成本清楚的改动。
- Windows 版本质量优先于跨平台扩张。
- 功能取舍以 [产品边界](PRODUCT.md) 为准。

## 维护者权限

UI、发布链路、更新器、安全、许可和品牌相关改动，即使验证通过也需要维护者确认。

维护者可以关闭不符合产品边界、风险过高、验证不足、法律来源不清或维护成本过高的 Issue / PR。

## 治理变更

治理规则本身也可以通过 PR 调整。如果未来加入长期维护者，应先更新本文件，写清楚职责、权限和交接方式，再授予仓库或发布权限。
