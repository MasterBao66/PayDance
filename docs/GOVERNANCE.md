# 治理说明

> [English version →](GOVERNANCE_EN.md)

PayDance 目前采用单一维护者模式。维护者身份见[维护者说明](MAINTAINERS.md)，提交流程见[贡献指南](../.github/CONTRIBUTING.md)。

## 决策方式

维护者对产品范围、合并、发布、安全、许可和商标拥有最终决定权。决策主要依据：

- 是否符合[产品边界](PRODUCT.md)
- 用户收益与 Windows 版本质量
- 验证结果、风险和维护成本
- 代码与素材的来源和许可是否清楚

超出范围、缺少验证、风险或维护成本不明确的 Issue 和 PR 可以关闭或暂缓。

## 治理变更

治理规则可以通过 PR 修改。授予新的仓库或发布权限前，应先在本文件和[维护者说明](MAINTAINERS.md)中写清职责、权限和交接方式。
