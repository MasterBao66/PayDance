# PayDance 设计规范

本规范适用于主界面、迷你悬浮、设置中心、首次向导和 Web Preview。

## 设计原则

- 遵循 Windows 11 桌面工具的简洁层次，减少装饰和视觉噪声。
- 今日入账金额始终是第一视觉焦点。
- 橙色仅用于收入、进度、焦点和必要反馈，不作大面积背景色。

## 信息层级

1. 今日入账金额。
2. 当前状态、已工作时间、距离上班或下班、今日预计。
3. 今日进度。
4. 薪资说明、设置和托盘等低频入口。

主界面只保留金额层和看板层，不再叠加独立卡片、徽章或说明层。

## 窗口

- 主窗口使用无边框大圆角，不启用原生阴影。
- 顶部状态区和窗口按钮保留足够内边距。
- 设置中心和薪资说明打开后，背景空白处及弹层标题栏仍可拖动窗口。
- 首次向导使用较高不透明度，避免主界面内容干扰阅读。
- 迷你窗口只显示金额；右键打开轻量透明度面板，不增加常驻控件。
- Web Preview 在浏览器舞台中呈现应用窗口，页面背景不与主界面争夺注意力。

## 主题与色彩

- 浅色主题使用白色层级、浅边框和低强度阴影。
- 深色主题使用清晰的近黑层级，避免泛白高光和凹槽效果。
- 进度条保持平面清晰；进度圆点可有轻微光感，不使用扩散发光。
- 主题切换必须同步页面与原生窗口主题，避免边框、四角或背景短暂错色。

## 字体与数字

- 金额和看板数字使用 `--font-dashboard`，不得在局部组件另设不一致的数字字体。
- 设置、薪资说明和首次向导中的数字、英文及符号沿用同一字体变量。
- `h`、`m`、货币符号与数字之间保留清晰间距。
- 金额整数为主，小数降低视觉权重。

## 动效

- 金额变化可使用短促、克制的脉冲，不增加持续环境光或大面积呼吸光。
- 保留键盘焦点可见性，并遵循系统的减少动态效果偏好。
- 金额滚动与静态显示由用户设置控制。

## 组件边界

- 设置按任务分组，不压缩成连续密集表单。
- 薪资说明只展示日薪、时薪、分薪和秒薪，不承载设置操作。
- 透明度面板与迷你窗口对齐；右键只负责打开面板，不改变迷你窗口位置。
- GitHub 入口保持可识别的按钮形态，但不占满设置面板宽度。
- Web Preview 隐藏托盘、置顶和开机自启动等桌面能力；迷你窗口和透明度可在浏览器内模拟。

## 验收

- 同时检查浅色、深色、中文和英文，确保文字不重叠、控件不溢出、焦点状态可见。
- 桌面改动覆盖受影响组件的行为测试，并按[桌面端冒烟清单](desktop-smoke-checklist.md)检查真实窗口能力。
- Web Preview 改动运行 [Web Preview QA](web-preview-qa.md)；只有确认视觉变化符合预期后才更新基准图。
