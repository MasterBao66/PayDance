# 商标政策

> [English version →](TRADEMARK_EN.md)

本政策规定 PayDance 名称、标识和官方渠道的使用边界，避免第三方版本与官方版本混淆。本政策不改变 `LICENSE` 授予的代码使用权。

## 受保护标识

以下名称、标识和来源识别元素由作者 Mr.Baoboer 保留：

- **“薪跳”**
- **“PayDance”**
- **“薪跳 PayDance”**
- PayDance Logo、应用图标与托盘图标
- 官方宣传海报、社交预览图、官网视觉识别
- 官方截图中可识别的完整产品视觉组合
- 官方 GitHub 仓库、Vercel 主站、GitHub Pages 镜像、Release 下载渠道、更新端点和签名发布链路
- 用于识别官方版本的应用标识符、包元数据和发布资产名称

## 允许的事实性使用

无需事先书面许可，你可以：

- 如实说明项目“基于 PayDance”“forked from PayDance”或“兼容 PayDance”
- 链接到官方仓库、官网或 Release 页面
- 在讨论、评测、教程、新闻、学术材料或安全报告中提及“薪跳”或“PayDance”
- 在保留许可证、版权和来源声明所必需的范围内复制名称

这些使用必须清楚、准确，不得暗示官方背书、合作或认证。

## 需要事先书面许可的使用

未经明确书面许可，不得：

- 以“薪跳”“PayDance”“薪跳 PayDance”或容易混淆的名称发布修改版或衍生产品
- 将官方 Logo、应用图标、托盘图标、海报或官网视觉作为修改版产品标识
- 通过官方发布渠道、更新端点、签名链路或发布资产命名分发修改版
- 暗示修改版由 Mr.Baoboer 或 PayDance 项目制作、批准、赞助、认证或背书
- 使用 PayDance 品牌推广无关的产品、服务、课程、社群或商业活动

## 修改版与 Fork 的最低区分要求

分发修改版、二进制构建、安装包、便携版或在线版本时，必须让普通用户能够清楚分辨其并非官方 PayDance。至少应替换或修改：

- 产品名称
- 应用图标和托盘图标
- 应用标识符、包名、窗口标题和包元数据
- 官网、下载页、更新端点和签名公钥
- Release 资产命名、安装包名称和自动更新清单
- README、“关于”视图和法律声明中的官方性表述

可接受的名称示例：

- `MySalary（基于 PayDance 修改）`
- `工资助手（forked from PayDance）`
- `Acme Earnings Display, based on PayDance`

不可接受的名称或标识示例：

- `PayDance Plus`
- `薪跳 Pro`
- `PayDance CE`
- 使用官方 PayDance 图标但只在角落写一个小字说明的修改版

## 官方版本说明

除非另有公告，PayDance 官方发布渠道仅包括 [MrBaoboer/PayDance 仓库](https://github.com/MrBaoboer/PayDance)、该仓库的 [GitHub Releases](https://github.com/MrBaoboer/PayDance/releases)、[Vercel 主站](https://paydance.vercel.app/)和 [GitHub Pages 镜像](https://mrbaoboer.github.io/PayDance/)。Vercel 主站是规范官网。
