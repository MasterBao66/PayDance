## 它是什么

薪跳 PayDance 是一款桌面实时工资看板。填好薪资和上下班时间，今日入账就在桌面上持续增长，工作进度、剩余时间和今日预计一眼看清。

想专注时切到迷你悬浮窗：只留一行金额，放在屏幕角落随时扫一眼。

## 主要功能

- **实时入账**：今日入账逐秒更新，精确到小数点后两位。
- **贴合真实工作制**：月薪、日薪、时薪自动换算，支持每周工作日、午休剔除和跨零点夜班。
- **迷你悬浮窗**：只显示金额，可拖拽、可置顶，透明度 10%–100% 可调，双击回到主窗口。
- **本地优先**：不需要账号，不上传数据，薪资配置只保存在你自己的电脑上。
- **中英双语**：界面、托盘和提示完整覆盖简体中文与 English。
- **Windows 桌面能力**：亮暗主题、托盘常驻、开机自启动、后台检查更新。

## 隐私

不需要登录，不上传数据，没有遥测。所有配置只保存在本机的 `salary-settings.json`，内容仅有薪资参数、工作时间和界面偏好。
